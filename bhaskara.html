Domine a fórmula de Bhaskara.

Organize os coeficientes, calcule o delta e encontre as raízes da equação.

1. A fórmula

A fórmula de Bhaskara permite encontrar as soluções reais de uma equação do segundo grau.

x = −b ± √Δ 2a

O símbolo ± indica que devemos considerar duas possibilidades: uma usando a adição e outra usando a subtração.

2. Calcule o discriminante (delta)

Δ = b² − 4ac

O valor de delta ajuda a entender quantas raízes reais a equação possui.

Δ > 0

Duas raízes reais

Existem duas soluções reais diferentes.

Δ = 0

Uma raiz real

As duas soluções coincidem.

Δ < 0

Nenhuma raiz real

Não há soluções no conjunto dos números reais.

3. Experimente a calculadora

Digite os valores de a, b e c. O coeficiente a não pode ser zero.

RESULTADO

Preencha os coeficientes e clique em calcular.

4. Passo a passo de um exemplo

Vamos resolver a equação x² − 5x + 6 = 0.

01

Identifique: a = 1, b = −5 e c = 6.

02

Calcule o delta: Δ = (−5)² − 4 · 1 · 6 = 25 − 24 = 1.

03

Substitua na fórmula: x = (5 ± √1) / 2.

04

Encontre as raízes: x₁ = (5 + 1) / 2 = 3 e x₂ = (5 − 1) / 2 = 2.

✓

Resposta: as raízes são x = 2 e x = 3.
